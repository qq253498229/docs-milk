- [x] 优先升级挤奶+锻造，轮流升级。注意冲泡20级的锻造茶能+3锻造等级，提前获取工具

- [x] 剪刀和蒸馏器各准备两个
- [x] 剪刀强化到+4就行，蒸馏器保6争7
- [x] 强化蒸馏器的时候先强化A到+5，再强化B到+6，回过头来强化A到+7，这样循环直到材料耗尽
- [x] 升级路上箱子开出的宝石碎片，用炼金转成珍珠和星星碎片，做采集戒指和采集耳坠
- [x] 后期星星碎片多了之后做效率项链
- [x] 3件首饰集齐后慢慢补强化等级
- [x] 开始升级房子，采集和炼金到2级。木板靠转化；精华主要靠重置，其次靠分解材料
