铁牛打金

1. 最终目标：

  • 锻造86级

  • 采集80级，剪刀+4

  • 炼金80级，蒸馏器+6

  • 采集房屋2级

  • 炼金房屋2级

  • 采集杨桃——分解杨桃——点金采集精华,无限循环产出金币

  • 每小时约有 224k 金币，即每天 5.38M 金币。

2. 流程：

  • 优先升级挤奶+锻造，轮流升级。注意冲泡20级的锻造茶能+3锻造等级，提前获取工具

  • 其次升级采集

  • 炼金靠点金采集产物，重置牛奶产出木头升级

  • 一直升级到锻造86+采集80的时候准备强化工具

  • 剪刀和蒸馏器各准备两个

  • 剪刀强化到+4就行，蒸馏器保6争7

  • 强化蒸馏器的时候先强化A到+5，再强化B到+6，回过头来强化A到+7，这样循环直到材料耗尽

  • 升级路上箱子开出的宝石碎片，用炼金转成珍珠和星星碎片，做采集戒指和采集耳坠

  • 后期星星碎片多了之后做效率项链

  • 3件首饰集齐后慢慢补强化等级

  • 开始升级房子，采集和炼金到2级。木板靠转化；精华主要靠重置，其次靠分解材料

  • 开始刷钱：

  • 买牛玲3队列

  • 采集杨桃——分解杨桃——点金采集精华,无限循环产出金币购买各种装备

  • 大概30天左右就能到最后一步

分解杨桃一次需要900金币！！
